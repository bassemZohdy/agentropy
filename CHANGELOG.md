- **FEAT-033** (feat): Multi-worker correctness and scale: shared policy-cache invalidation and indexed wake-ups (R-05, R-06). Ref: docs/review/2026-11-06-project-review.md#runtime-and-scale. Validated: `pnpm exec vitest run packages/runtime/test packages/testkit/test`. Docs: updated docs/contracts/security-v1.md (revision 8), docs/security/threat-model.md, docs/runtime-contract.md, docs/conformance-kit.md, docs/compatibility.md, docs/api.md. Notes: `CachingPolicyDecisionPoint` with `shared: { store, syncMs }` applies invalidations any worker recorded in the new `policyInvalidations` collection; `revokeAuthority` records one in its audit transaction, so a revoked grant stops being served everywhere within `syncMs` (default 1 s) instead of `ttlMs`; a failed read clears the cache; rows keep only the grant digest and are pruned after 10 min. Wake-ups carry an indexed `checkAt`: polls read only due or signalled registrations (events, human actions, local and remote children set it in their own transaction) plus a full scan every 60 s as a backstop; at 10k armed registrations a poll fell from 302 ms to 3.2 ms on SQLite.

### Changed — re-review (2026-11-04)

Independent re-review after merging the design review found 25 issues, all fixed ([review record](docs/review/2026-11-04-design-review.md#re-review-after-merge)):

- Effect journal committed at invocation time, not with the disposition (AC-07 was impossible).
- Durable event subscriptions with per-task mailboxes, so events arriving between activations are not lost.
- Conversation turn model (`submitTurn`, briefing at turn start); rule-based conversational agent possible.
- Human-action decisions checked against the request before task state; one expiry mechanism (`onExpiry`).
- Guard order puts idempotency replay before state checks; full refusal lists; retry policy and cancel grace period defined; execution edges for queued aborts.
- `TaskEvent` ordering by `(revision, sequence)`; `notificationCreated` event feeds the inbox; `InboxEntry` type.
- Agent v1 rev 3: `DelegateInput`, `HandlerRegistry`, instance and human-action operations, record types, richer `WakeReason`.
- POC scope: journeys reworked; AC-15…AC-20 added; requirement mappings corrected.
