# API reference

Generated by `node scripts/api-index.mjs` from each package's entry point; CI fails when it is out of date. Exported symbols are listed with their kind, source file and the first sentence of their doc comment. Nothing here is API-stable yet (pre-1.0); behaviour is specified by the [contracts](contracts/) and claimed only where a test exists. Start with the [quickstart](quickstart.md); version support is in the [compatibility matrix](compatibility.md).
