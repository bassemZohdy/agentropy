# 2026-11-06 — Deep review: fixes and improvements after FEAT-034

**What this is:** a second, code-level sweep of the whole repository after the [first project review](2026-11-06-project-review.md) (R-01…R-26) and the FEAT-032/033/034 work it produced. Every source module under `packages/*/src`, the example host, the stores, the deployment files, the CI workflow, the scripts and the documents they reference were read in full; the offline suite was run with V8 coverage. Findings continue the `R-nn` numbering (R-27…R-59) and each names the backlog root that owns it in [TODO.md](../../TODO.md). Line numbers refer to commit `b5c79a1`.

Severity: **high** = a production deployment would hit it (data loss, a dead process, a security hole or unbounded cost); **medium** = a wrong result in a supported case, or cost that grows with data the deployment is meant to hold; **low** = hygiene, documentation or developer experience.

## Coverage baseline (TASK-037.1)

With workspace packages resolved to their sources (`vitest.config.ts` aliases `@agentropy/*` to `packages/*/src`), `vitest run --coverage` on 2026-11-07 measures **94.4% lines, 86.35% branches, 93.55% functions** over `packages/*/src` (537 tests). The 88.25% / 82.57% recorded above came from tests resolving other packages to `dist`, which attributed their execution to no source file. ## Checked and found sound

Not every area produced a finding. These were read with the same care and hold up: tenant checks before every policy decision and `NotFound` for invisible resources (AC-04/AC-09); the idempotency insert as the acceptance fence with the concurrent-duplicate repair; lease epochs fencing every late write; the audit intent committed with the change it describes and the per-tenant chain head; sealed webhook secrets and the refusal to store them unsealed; the SSRF guards on push URLs and federation cards; A2A part validation (one of `text`/`raw`/`url`/`data`, base64 and scheme checks, at most 16 parts); bounded HTTP bodies and open streams; the process-global network guard; SHA- and digest-pinned supply chain with the production audit; additive schema evolution refusing newer databases; the reference-SDK interop test in both directions.
