The diagrams are drawn by [archgram](https://www.npmjs.com/package/archgram) from the specs beside them. Every box and line in a spec names the file (and the line of code) behind it, so `npx archgram@0.10.1 check docs/diagrams/<name>.archgram.yaml` fails when the code a diagram describes has moved. After changing a spec, run `build` on it and commit the SVG. The demo is rendered from the example's real output (build first with `pnpm exec tsc -b`; the video needs ffmpeg).
