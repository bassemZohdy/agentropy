## Objective

Create the smallest offline-verifiable TypeScript workspace that enables a test-first Agentropy implementation and a valid todo-skills task tree. Do not start implementing delegation, runtime, A2A or production infrastructure under this scaffold task.

## Decisions already accepted

- TypeScript strict, ESM, supported Node.js LTS; pin specific runtime/tool versions after verifying current support.
- pnpm workspace, JSON Schema 2020-12, Vitest.
- ESLint + Prettier.
- SQLite WAL, single process with pluggable Store abstraction for M1; polling scheduler, in-process events and transactional outbox.
- Apache-2.0 license and DCO in CONTRIBUTING.
- AgentProfile `task` requires `durable-execution`.
- ADR-0024 pre-dispatch authorization eligibility gate: no new task lifecycle statuses.

During actual todo-skills planning each leaf must have one executable `Done when` command checked in the real workspace. Use the current repo's confirmed naming, not the hypothetical `@agentropy/core` path above, unless explicitly adopted.

## CI and security smoke checks

- Prove a deterministic test runs with network access disabled; no LLM, A2A server, OPA, Keycloak or cloud secrets are required.
- Validate license and DCO contribution policy, no sensitive files and no imported foreign project code.
- Confirm workspace packages can be imported using their public entry points in strict TypeScript.
- Record dependency versions and pinned Node runtime; no optimistic platform/version compatibility claims.
- Run todo-skills lint after a confirmed migration, preserving all legacy M*/D-/X-/C- items through an explicit crosswalk.

## Exit gate

- All future scaffold leaves verified and merged under their own task branches.
- Real CLI targets exist and pass.
- A valid todo-skills TODO tree exists only after lossless migration approval.
- CHANGELOG updated with verified evidence and plan links.
- M0-08 may then be checked, and M1 implementation separately authorized.
